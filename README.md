# Мастерская по ремонту бытовой электроники

Информационная система для автоматизации учёта ремонтных работ, управления складом запчастей и ведения клиентской базы. 

## Стек технологий

### Фронтенд
- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5 (адаптивный интерфейс)
- LocalStorage (офлайн-хранение данных)
- PWA (Progressive Web App)

### Бэкенд
- Python 3.11+
- FastAPI (веб-фреймворк)
- SQLAlchemy (ORM для работы с PostgreSQL)
- PostgreSQL 18 (база данных)
- Argon2 (хеширование паролей)

## Установка и запуск

### 1. Требования
- Python 3.11 или выше
- PostgreSQL 18
- Git
